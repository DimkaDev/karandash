and Angular strictTemplates are explicit. Direct versions and package-lock.json

## Dependency finding

The initial audit reported high-severity Vite advisories via @angular/build,
which pins Vite 8.3.0. A scoped override selects patched Vite 8.3.3 for that builder
only. Audit after reinstall/clean install reports zero known findings. Build,
unit tests and dev server were tested with the override. Remove it only after
reviewing a patched builder release and rerunning those checks.

npm emitted warnings about dependency install scripts without allowScripts entries;
no blanket permission was added and no scripts were manually approved. The clean
install, build, tests and lint succeeded without doing so. Registry audit is not
a complete supply-chain security assessment.

Node archive SHA-256 matched the official Node.js SHASUMS256.txt before extraction.
System Node.js was unchanged. Temporary runtime paths are evidence for this run,
not required installation locations for developers.
